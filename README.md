# ML in Motion

An interactive website that teaches machine learning through animated 3D simulations built with
[Three.js](https://threejs.org/), all applied to one real COVID-19 dataset. Every lesson runs the real algorithm live in the browser, so you can
watch it learn, change its settings, and orbit around the scene.

## One real dataset: COVID-19

Every lesson uses the same real data: **COVID-19 statistics for 131 countries** from
[Our World in Data](https://github.com/owid/covid-19-data) (CC BY 4.0), as of 31 Dec 2022. The data covers cases, deaths,
vaccination, median age, GDP, hospital beds, life expectancy, HDI and lockdown stringency, plus weekly epidemic curves. The
first tab, **Meet the Data**, is a 10-step guided walkthrough covering rows and columns, features vs. target, distributions,
log transforms, correlation vs. causation, time series, scaling, train/test splits and labels.

Each lesson explains the concept, shows how it applies to the COVID data, and includes a **real-life scenario** box.

## Lessons

Every algorithm lesson shows **🎯 the output we want** from the model and **🛠 how to use the trained model**. Supervised
lessons follow the same four-step pipeline (prepare data → split → train & optimise → evaluate) on one fixed 80/20 split:
107 training countries (spheres) and 24 test countries (cubes). Each one reports test-set performance and has a
**“Use the trained model”** panel: set feature values or load a real country and get the model's prediction.

## Voice narration

Press **🔊 Narrate** in the top bar to have each lesson read aloud: its goal, the explanation, and how to use the model.
Step-by-step lessons (Meet the Data, How Supervised Learning Works) narrate each step as you advance. Narration uses the
browser's built-in speech synthesis (Web Speech API), so it works offline and nothing is sent to a server. Available voices
depend on the browser and operating system.

## Rebuilding the data

`js/data/covid-data.js` is generated by `scripts/build_covid_data.py` (requires pandas):

```bash
curl -L -o owid-covid-data.csv \
  https://raw.githubusercontent.com/owid/covid-19-data/master/public/data/owid-covid-data.csv
python3 scripts/build_covid_data.py owid-covid-data.csv
```

Lessons read the data through `js/data/covid.js`, which provides the field dictionary, scaling helpers and shared labels.

## Running locally

The site is plain HTML/CSS/JS ES modules with no build step. Three.js loads from a CDN through an
import map, so any static file server works:

```bash
python3 -m http.server 8000
# or
npx http-server -p 8000
```

Then open <http://localhost:8000>. Opening `index.html` directly from disk won't work because browsers
block ES module imports over `file://`.

## Deploying

Because it's fully static, you can publish the repository as-is with **GitHub Pages** (Settings → Pages →
deploy from branch, root folder), Netlify, Vercel, or any static host.

## Project structure

```
index.html            App shell and import map
css/style.css         Layout and theme
js/main.js            Renderer, camera, navigation, lesson UI builder
js/helpers.js         Shared Three.js utilities (instanced points, labels, colours, RNG)
js/data/covid-data.js Generated COVID-19 dataset (do not edit by hand)
js/data/covid.js      Dataset helpers: field labels, z-scoring, labels, quantiles
scripts/              Data build script
js/narrator.js        Voice narration (Web Speech API)
js/ml/                Shared ML code: train/test point clouds, metrics, trees, predictor panel
js/lessons/*.js       One file per lesson
js/lessons/index.js   Lesson order shown in the sidebar
```

## Adding a lesson

Create `js/lessons/my-topic.js` that exports a lesson object, then add it to `js/lessons/index.js`:

```js
export default {
  id: 'my-topic',                 // used in the URL hash (#my-topic)
  title: 'My Topic',
  category: 'Supervised Learning',
  camera: { position: [0, 0, 16], target: [0, 0, 0] },
  formula: 'ŷ = f(x)',             // shown in the panel (HTML allowed)
  hint: 'One-line caption under the scene',
  info: '<h3>What it is</h3><p>…</p>',
  create({ scene, ui, setCamera, onClick }) {
    // Build Three.js objects into `scene`; add controls with
    // ui.slider / ui.button / ui.select / ui.toggle / ui.stat / ui.html.
    return {
      update(dt, elapsed) { /* advance the simulation each frame */ },
      dispose() { /* optional extra cleanup */ },
    };
  },
};
```

Scene objects are disposed automatically when you switch lessons.

## Controls

- Drag to orbit, scroll or pinch to zoom
- `Space` pauses or resumes, `←` / `→` switch lessons
- The **Speed** slider scales every simulation
